# 忘却曲線 復習トラッカー (Ebbinghaus Spaced Repetition Tracker)

エビングハウスの忘却曲線に基づいた、**動的間隔反復（Spaced Repetition）学習トラッカー**です。  
実際の学習は本やノート等で行い、アプリは**「今日何を復習すべきかを表示し、完了を記録する」**ことに特化しています。

スマホの Chrome で「ホーム画面に追加」することで、通常のスマホアプリと同様に全画面で快適に動作します（PWA対応）。

---

## ✨ 主な特徴

1. **エビングハウスに基づく2ステップ復習**
   - **登録日（Day 0）:** 学んだ内容を入力するだけで、翌日に「1回目の復習」が自動設定されます。
   - **1回目完了（Day 1）:** 完了を記録した日を起点に、**+6日後**に「2回目の復習」が自動設定されます。
   - **2回目完了（Day 7）:** 記憶定着マスターとして達成されます。
2. **動的リスケジュール（遅延の自動持ち越し）**
   - 予定日に復習できず日が空いてしまっても、「遅延」として責められることはありません。
   - すべてフラットに**「今日やるべき復習」**に集約され、実施した日を基準に次回の間隔が再計算されます。
3. **何回目の復習かが一目でわかるバッジ**
   - `1回目の復習`（青バッジ）、`2回目の復習`（紫バッジ）が明確に表示されます。
4. **アプリ内学習なし・記録特化の高速UX**
   - ワンタップで完了を記録。誤操作時の「元に戻す（Undo）」機能付き。
5. **完全無料・プライバシー重視（ローカルファースト）**
   - データはお手元の端末（LocalStorage）に保存され、ログイン不要で即座に使えます。
   - JSONファイルでのバックアップ＆復元にも対応。

## 🚀 GitHub Actions で GitHub Pages に公開する手順

本リポジトリは GitHub Actions による自動デプロイに対応しています。

### 1. GitHub にリポジトリを作成してプッシュ
```bash
cd ebbinghaus-app
git init
git add .
git commit -m "Initial commit: Ebbinghaus review tracker"
git branch -M main
git remote add origin https://github.com/<YOUR_USER>/<YOUR_REPO>.git
git push -u origin main
```

### 2. GitHub Pages の設定
1. GitHub リポジトリの **[Settings]** タブを開きます。
2. 左メニューの **[Pages]** を選択します。
3. **Build and deployment > Source** を **「GitHub Actions」** に変更します。
4. 次回プッシュ時（または Actions タブから手動実行）に自動的にビルドされ、公開URLが発行されます。

---

## 📱 スマホ（Chrome）でアプリとして使う方法

1. 発行された GitHub Pages の URL をスマートフォンの Chrome で開きます。
2. 画面右上のメニュー（**︙**）をタップします。
3. **「ホーム画面に追加」**（または「アプリをインストール」）を選択します。
4. ホーム画面にアイコンが追加され、タップするとアドレスバーのない全画面ネイティブアプリとして起動します。
